### Step 2: Run Supabase Migration (If Not Done Yet)

1. Go to: https://supabase.com/dashboard
2. Select: **NAKIVO Reminder Project**
3. Navigate to: **SQL Editor** → **New Query**
4. Open: `supabase-add-distributor-reseller-fields.sql`
5. Copy and run the SQL

### Step 3: Clear Existing Data (Optional - Only If You Want to Replace All)

1. In Supabase Dashboard, go to: **Table Editor**
2. Select: **customers** table
3. Click the **checkbox** at the top to select all rows
4. Click **Delete** button
5. Confirm deletion

### Step 4: Import CSV

1. In **Table Editor** → **customers** table
2. Click the **"Insert"** button (top right)
3. Select **"Import data from CSV"**
4. Click **"Upload CSV file"**
5. Select your `customers_rows.csv` file (without the `id` column)
6. Map the columns:
   - Make sure CSV columns match Supabase column names
   - The system will try to auto-match
7. Click **"Import"**

### Step 5: Verify

1. Check the **customers** table - you should see your 3 customers
2. Go to your Vercel app: `https://your-app.vercel.app/admin`
3. The data should appear automatically!

## 🎯 Alternative: Use Supabase SQL Import

If the Table Editor import doesn't work, you can use SQL:

1. Go to **SQL Editor**
2. Create a SQL script to insert the data
3. Run it

## 📝 Notes

- After importing, Vercel will automatically show the new data (no deployment needed)
- The `id` column is auto-generated by Supabase
- Dates will need to be converted from `DD-MM-YY` to `YYYY-MM-DD` format
- Make sure all required columns exist (run migration first)
